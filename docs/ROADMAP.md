## A. リアル版（軌道力学・姿勢力学込み）

現行版は「宇宙空間で慣性運動する船と、空間に固定された回転ステーション」というモデルで、
物理の基本は正しいが、数値と一部の現象はゲーム向けに簡略化している。
リアル版はそれを本物寄りにした別モード（「リアルモード」）として用意する想定。

### A-1. 軌道力学（相対運動）
- ステーションは地球低軌道（例: 高度 400 km、周期 約92分、平均運動 n ≈ 0.00113 rad/s）を周回。
- 船の運動はステーション基準の回転座標系（LVLH）での相対運動として、
  **Clohessy–Wiltshire（Hill）方程式**で計算する。
  - 前方（進行方向）へ噴射すると高度が上がり、結果として後ろへ下がっていく、などの直感に反する動きが出る。
  - 上下（動径方向）にずれた船は、前後方向へ流されていく。
- 接近方式を選べる：V-bar（進行方向から）／R-bar（地球側から）。
  R-bar 接近は重力傾斜で自然にブレーキがかかるので安全、などの違いが体験できる。
- 実際の接近は数km先から数時間かかるため、**時間加速**（×1〜×100）が必須。
- 遠距離はゲート表示ではなく、相対軌道の予測線（2D/3D）で航法する。

### A-2. 姿勢力学
- 船の慣性テンソルを入れ、**オイラーの運動方程式**で回転を計算する。
  - 高速ロール中にピッチ・ヨーを入れると、コマのように首振り（歳差・章動）が起きる（ジャイロ効果）。
- ステーション側も慣性テンソルを持たせ、トルクフリー運動として計算する。
  - 中間主軸まわりの回転は不安定（ジャニベコフ効果）なので、「不規則に転がる（タンブリング）ステーション」が物理から自然に出せる。

### A-3. 推進系
- 推力を実機相当に（例: 質量10 t の船に数百N級スラスタ → 0.01〜0.05 m/s² 程度）。
- 推進剤は比推力（Isp）とツィオルコフスキーの式で質量として減っていく（軽くなるほどよく効く）。
- スラスタの配置と重心のずれから、並進のつもりの噴射でもわずかに回転が生じる（干渉）。
- 最小インパルス（ちょん押しの最小量）を設定。

### A-4. センサー・表示
- テレメトリに誤差とノイズを加える（レーザー測距の精度、更新レート）。
- 「真の値」ではなく計測値で操縦する。カメラ映像と測距の数値が少し食い違うこともある。

### A-5. ドッキング機構
- 許容範囲を実機相当に厳しく：接触速度は秒速数cm、横ずれは十数cm、角度は数度程度。
- 捕獲（ソフトキャプチャ）→ 減衰 → 引き込み（ハードキャプチャ）の段階を表現。
- 噴射ガスがステーションに当たる影響（プルーム）で、近距離では前方への噴射が制限される。

### A-6. 環境
- 昼夜サイクル（約92分周期のうち、地球の影に入る時間が約1/3）。夜側は船のライトと計器だけが頼り。
- 太陽の方向によっては、まぶしくてカメラが使えない時間帯がある。

### A-7. 実装方針メモ
- `Sim` と同じインターフェース（`step` / `telemetry` / `evaluate`）のまま、物理エンジンだけ差し替えられる形にする。
- 積分は RK4。テストとして、外力なしでのエネルギー・角運動量の保存や、CW方程式の解析解との一致を確認する。
- 現行のオートパイロットはそのままでは使えないので、リアル版専用の誘導則（CW誘導など）が必要。

## B. 操作の救済策（現行版向け）

- **回転停止ボタン**：自船のロール回転を自動で0に戻す。回転を合わせるタイミングを誤ったときの立て直し用。
- **姿勢リカバリー**：ロール回転は維持したまま、機首だけをステーションの軸に向け直す。
- **軸合わせ補助**：前進中も機首を軸方向に保ち続ける（前進で横流れが出る原因の一つを消す）。
- **やさしいモード**：許容範囲を広げる、スラスタの効きを穏やかにする。
- 補助を使った場合はスコアに反映（現行の回転ロックと同じく倍率＋表示）。

## C. ステージ候補

| 候補 | 内容 | 新しい難しさ |
|---|---|---|
| **上部ポート・ドッキング** | 船の上面にあるドッキングポートで結合する。機首は横を向いたまま、お腹側を見上げる形で滑り込む | 機首方向と結合方向が90°違う。上向きカメラが必要。前進キーでなく「上」キーで接近 |
| タンブリング・ステーション | 1軸回転ではなく、不規則に転がるステーション | 軸そのものが大きく動き続けるので、追従し続ける必要がある |
| リング外周ポート | ハブではなく、回転するリング側のポートに結合 | ポートが円運動しているので、船も円を描き続けなければならない（向心加速度に推力が足りるか） |
| 夜側ドッキング | 地球の影の中。ステーションは誘導灯と自船のライトでしか見えない | 視覚情報の制限、計器飛行 |
| デブリ帯 | 破片が漂う中を接近 | 回避しながらの接近、時間制限 |
| 推進剤ギリギリ | 推進剤が極端に少ない | 無駄な噴射ができない、省エネ航法 |
| 分離・離脱 | ドッキング状態から、回転を止めて安全に離れる | ドッキングの逆手順、回転中の離脱方向 |
| 長距離ランデブー | 数km先から軌道力学込みで接近（A のリアル版前提） | 軌道力学の直感に反する動き |

## D. マニューバ編（ブラックホール周回と時間の遅れ）

**D-1 の範囲は MANEUVER 01「時の惑星」として実装済み。** 最後の母船合流を既存のドッキングにつなげるのは未実装。

### D-1. 流れ（最初に作る範囲）
1. 母船の周回軌道から減速し、ブラックホールに近い軌道へ降りる
2. 強い重力の惑星へ着陸する（逆噴射での降下）
3. 再び上昇して軌道に戻り、母船と合流する（最後は既存のドッキングにつなげる）

- 画面に「自分の時計」と「外の世界の時計」を並べる。惑星の近くにいる1分ごとに、外では何年も過ぎていく。
- スコアは、使った推進剤と外の世界で過ぎた年数。早く戻るほど高い。

### D-2. 物理
- 「惑星での1時間が外の約7年」（約6万倍の時間の遅れ）は、ほぼ限界まで高速自転しているブラックホール
  （カー・ブラックホール）のごく近くの円軌道でなら成り立つ。
- 赤道面の円軌道での時間の遅れは、カー時空の式で正確に計算できるので、ここは本物の計算を使う。
- 軌道運動そのものは、ゲームとして扱える近似の重力モデル（最内安定円軌道を持つ擬ニュートン的なポテンシャルなど）を使う。
- 画面は、軌道の操縦は真上から見た2D軌道図、着陸は3D、という組み合わせが有力。

### D-3. ワームホール：カット
- 理論上のワームホールは通過が一瞬で、外からは「球形の窓の向こうに別の場所の星空が歪んで見える」だけになる。
  中を長く旅するトンネルの映像は映画の演出なので、操縦する場面としては採用しない。
- 雰囲気づくりとして、背景に「別の星空が歪んで映る球」を置く案だけ残す（任意・低優先）。

### D-4. 名前
- ブラックホール・惑星ともにオリジナルの名前を付ける（映画の固有名は使わない）。
