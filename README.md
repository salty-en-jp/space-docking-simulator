# SPIN SYNC — 回転ステーション・ドッキング・シミュレータ

高速で自転する宇宙ステーションに、**自分の船も同じ速さで回転させて**ドッキングする、ブラウザで動くシミュレータです。
回転がそろった瞬間、窓の外の世界がぐるぐる回り、ステーションだけが静止して見えます。

ビルド不要の素の HTML + JavaScript（Three.js 同梱）で、静的ホスティング（GitHub Pages など）にそのまま置けます。

## 遊び方

```bash
npm start            # = python3 -m http.server 8000
```

ブラウザで http://localhost:8000 を開きます（ES モジュールを使うので、HTML ファイルを直接開くのではなくローカルサーバ経由で）。

### ミッション

| | 回転数 | 内容 |
|---|---|---|
| MISSION 01 訓練飛行 | 2 rpm | 画面に手順のヒントが出ます。まずはここから |
| MISSION 02 補給ランデブー | 8 rpm | 人工重力のために回転するステーションへの補給 |
| MISSION 03 居住区画への帰還 | 18 rpm | 高速回転。回転ロックの練習に |
| MISSION 04 制御不能 | 36 rpm | 軸もぶれながら落下中。制限時間5分 |

タイトルの「デモを見る」で、自動操縦による限界ミッションのドッキングを見られます（Z キーでいつでも操縦を交代できます）。

### 操作

| キー | 動作 |
|---|---|
| W / S | 前進 / 後退 |
| A / D | 左 / 右へ平行移動 |
| R / F | 上 / 下へ平行移動 |
| ↑ ↓ ← → | 機首の向き（ピッチ / ヨー） |
| Q / E | 反時計回り / 時計回りにロール |
| Shift（押しながら） | 微調整モード |
| X（押しながら） | 横流れを止める |
| L | 回転ロック オン / オフ |
| T | 姿勢安定装置（SAS）オン / オフ |
| C | カメラ切り替え（追従 / ドッキング / シネマ） |
| Z | オートパイロット |
| M | 音楽オン / オフ |
| H | 操作一覧 |
| Esc | 一時停止 |

スマートフォン・タブレットでは画面下のボタンで操作できます。

### ドッキングの手順

1. 照準（○）をポートの◇に向ける
2. 横移動でゲート列の中心（軸線）に乗る
3. Q/E で回転差を 0 に（ゲートとステーションが止まって見える）
   - **回転ロック**（L キー／スマホは「回転ロック」ボタン）をオンにしておくと、回転差が 3 rpm 以内になった時点でステーションと同じ回転を自動で保ちます。ロール操作中は手動優先。使うとスコア 0.9 倍
4. Shift + Q/E でオレンジのマーカーを真上にそろえる
5. W を軽く押してそっと前進

接触の瞬間に、接近速度・横ずれ・軸の角度・回転差・マーカー・首振りがすべて許容範囲内ならドッキング成功。
外れていると弾かれて船体が傷つき、速すぎると大破します。

## 構成

```
index.html          画面構成
css/style.css       見た目
js/sim.js           物理シミュレーション（描画に依存しない）・ミッション定義
js/autopilot.js     自動操縦（デモ＆クリア可能性の検証用）
js/models.js        ステーション・船・惑星・星空の3Dモデル
js/hud.js           HUD（進入ゲート・照準・ゲージ・数値パネル）
js/audio.js         Web Audio によるオルガン風BGMと効果音
js/input.js         キーボード / タッチ入力
js/main.js          ゲームループ・カメラ・画面遷移
vendor/             Three.js r160（MIT License）
test/sim.test.js    全ミッションを自動操縦でクリアできるかのテスト
```

```bash
npm test
```

ミッションの難易度（回転数・ぶれ・許容誤差・推進剤など）は `js/sim.js` の `SCENARIOS` で調整できます。

## 補足

名前・船やステーションのデザイン・音楽はすべてオリジナルです。
