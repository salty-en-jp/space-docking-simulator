# SPIN SYNC — 回転ステーション・ドッキング・シミュレータ

高速で自転する宇宙ステーションに、**自分の船も同じ速さで回転させて**ドッキングする、ブラウザで動くシミュレータです。
回転がそろった瞬間、窓の外の世界がぐるぐる回り、ステーションだけが静止して見えます。

ビルド不要の素の HTML + JavaScript（Three.js 同梱）で、静的ホスティング（GitHub Pages など）にそのまま置けます。

**▶ 遊ぶ：https://salty-en-jp.github.io/space-docking-simulator/** （PC・スマートフォン対応）

## このプロジェクトについて

### 制作の経緯

身近な宇宙SFファンに遊んでもらうために、「映画『インターステラー』のような、高速回転する母船へのドッキングを体験できるものを作りたい」というところから始まりました。
制作者（このリポジトリのオーナー）が企画・テストプレイ・判断を担当し、AI コーディングアシスタントの Claude Code（Anthropic）が設計・実装・検証を担当する、二人三脚で作っています。

映画はあくまで「場面の緊張感」と「仕組み」の参考です。船やステーションの名前・デザイン・音楽はすべてオリジナルです。

### 制作者のこだわり

- **雰囲気だけでなく、物理として正しいこと。**
  「これは当初の案で言うと、どの程度のリアルさなのか」を確認しながら進め、本物寄りのリアル版（軌道力学・姿勢力学込み）の構想も [docs/ROADMAP.md](docs/ROADMAP.md) に残しています。
- **映画の演出より、物理の正しさを取る。**
  ワームホールは、物理学者の「理論上は通過が一瞬で、中を旅するトンネルは演出」という解説を踏まえて、操縦する場面としては採用しませんでした。
  一方、「惑星での1時間が外の7年」は、本物の時間の遅れの式で再現することにしました。
- **実際に遊んで、違和感を見逃さない。**
  スマートフォンでのテストプレイから、次のような問題を見つけています。
  - 噴射エフェクトの左右が逆になっている
  - 横ずれ表示が、自船の回転を反映していない
  - 着陸レーダーのパッドの位置が前後逆になっている
- **難しさは残しつつ、理不尽にはしない。**
  - 毎分8回転と36回転の間に18回転のステージを足しました。
  - 回転を合わせるタイミングを誤っても、リセットせずに立て直せる仕組みを入れました。
  - 補助を使うかどうかはプレイヤーが選べます（使うとスコアは0.9倍）。
- **映画の場面に近い体験を。**
  船の**上面**のポートで回転する母船に結合する、上部ポートのミッションを入れました。
- **スマホでも、PCと同じように遊べること。**
  タッチ操作とレイアウトを、実機の画面を見ながら何度も調整しました。

### Claude のこだわり

- **描画と物理を分け、すべてのミッションがクリアできることを自動テストで保証する。**
  - 物理は描画に依存しない純粋なモジュールにしています（`js/sim.js`、`js/maneuver/*.js`）。
  - 自動操縦は、**プレイヤーと同じスラスタ性能・同じ操作入力だけ**で飛びます。この自動操縦で、ドッキング6ミッションとマニューバの往復を、テストのたびに実際にクリアさせています。
- **数字は計算で確かめてから使う。**
  - 「1時間 = 7年」（約61,362倍）は、カー・ブラックホールの赤道面・円軌道の式（自転 1 − a = 10⁻¹⁴）から求めています。惑星の軌道が最内安定円軌道の外側にあることも、テストで確認しています。
  - ホーマン遷移の噴射量と噴射タイミングも、ゲーム内の重力で数値的に解いています。
- **「それっぽい」より、物理として筋の通る動き。**
  - 回転中の噴射が渦を巻くように効くこと
  - ブラックホールの近くで軌道が少しずつ回ること（近点移動）
  - 近づきすぎると落ちること
  
  これらはすべて、運動方程式から自然に出てくるようにしています。

  開発中には、上部ポートを重心からずらして付けると、回転中にポートが円を描いて結合できないことがわかりました。これも本物の物理なので、設計の側（ポートを重心の真上に置く）で解決しています。
- **既存の作品を真似しない。**
  場面の仕組みは参考にしつつ、固有名・機体デザイン・音楽（Web Audio で生成するオルガン風の曲）はオリジナルにしました。
- **見て確かめる。**
  変更のたびに、PCとスマホ（縦・横）の画面をヘッドレスブラウザで撮影して確認しました。テストで見つけた不具合は、その場で直しています。
- **簡略化は正直に書く。**
  ゲームのために省いた物理（軌道力学、ジャイロ効果、実機相当の推力など）は、[docs/ROADMAP.md](docs/ROADMAP.md) に明記しています。

### マニューバ編：MANEUVER 01 時の惑星

母船の軌道から、ブラックホールのすぐそばを回る惑星へ降りて、データを回収して戻ってくるミッションです。
惑星の近くでは時間がおよそ6万倍ゆっくり進み、**そこでの1時間は外の世界の約7年**。画面上部に「あなたの時計」と「外の世界の時計」が並びます。

1. **軌道（2D軌道図）**：「噴射タイミング」が「今！」になったら逆行（R）で噴射し、惑星への遷移軌道へ。緑の予測線と「最接近」を見ながら修正し、近づいたら目標逆行（T）で相対速度を消す。
2. **着陸（3D）**：重力1.2Gの惑星へ逆噴射で降下。降下速度 3 m/s・水平速度 2 m/s・傾き 10° 以内でパッドに着陸。
3. **データ回収**：15分（船内時間）。その間にも外の世界では年月が過ぎていく。
4. **離陸して帰還**：高度600m・上昇速度15m/s以上で軌道へ戻り、母船とランデブー。

| キー | 軌道 | 着陸 |
|---|---|---|
| W / ↑ / Space | 噴射 | 噴射（W / Space） |
| A D / ← → | 機首の回転 | 左右へ傾ける（← →） |
| ↑ ↓ | — | 前後へ傾ける |
| P / R / T | 順行 / 逆行 / 目標逆行に向け続ける | — |
| , / . | 時間加速を下げる / 上げる | — |
| Z | 拡大表示 | — |
| L | — | 降下（上昇）速度の自動保持（スコア 0.9 倍） |
| Esc | 一時停止 | 一時停止 |

時間の遅れは、ほぼ限界まで高速自転しているブラックホール（1 − a = 10⁻¹⁴）の赤道面の円軌道の式で計算しています（`js/maneuver/relativity.js`）。
軌道運動は「近づきすぎると落ちる」性質を持つ擬ニュートン的な重力で計算しています。
ブラックホール・惑星の名前は仮のもので、`js/names.js` で変更できます。

タイトルの「デモを見る」で、自動操縦による限界ミッションのドッキングを見られます（Z キーでいつでも操縦を交代できます）。

### ドッキングの手順

1. 照準（○）をポートの◇に向ける
2. 横移動でゲート列の中心（軸線）に乗る
3. Q/E で回転差を 0 に（ゲートとステーションが止まって見える）
   - **回転ロック**（L キー／スマホは「回転ロック」ボタン）をオンにしておくと、回転差が 3 rpm 以内になった時点でステーションと同じ回転を自動で保ちます。ロール操作中は手動優先。使うとスコア 0.9 倍
4. Shift + Q/E でオレンジのマーカーを真上にそろえる
5. W を軽く押してそっと前進

接触の瞬間に、接近速度・横ずれ・軸の角度・回転差・マーカー・首振りがすべて許容範囲内ならドッキング成功。
外れていると弾かれて船体が傷つき、速すぎると大破します。

### 上部ポートと操作基準

MISSION 05・06 では、船の上面にあるポートで結合します。操作は既定で **ポート基準**
（W/S がポートの方向、Q/E がポート軸まわりの回転、カメラもポートの方向を向く）です。
実在の宇宙船にも、見ている窓に合わせて操縦桿の基準を切り替える仕組みがありました。
V キーで **機体基準**（W が機首方向、ポート軸まわりの回転は ←/→）に切り替えると、本物どおりの混乱が味わえます。
